# v6.2.0-beta.2 · 2026-10-29

- 阅读时间恢复轻量尽力而为模式：15秒首次、随后约60秒周期上报；首次时间请求取得一次可信的 Web 云端位置，随后同一阅读会话复用；不每分钟 GET 云端进度，不使用 Kindle 实时进度覆盖云端。
- 时间 Worker 复用经确认的 Reader 上下文；停用跨会话阅读时间债务恢复和模糊 POST 重放，休眠及断网期间不批量补报；最终进度同步及其确认事务独立保留。
- 后台阅读时间服务协议升至 31，排除旧 Worker；首次成功提醒改为单行「本次阅读时间已开始同步」，仅在服务端明确确认上报成功后展示。
- 评论获取新增「自选范围（默认）/ 当前章节」菜单；支持当前章起最多10章、自选任意起止章节和缓存复用。
- 独立评论子进程逐章下载及 SQLite 保存，新增章节级进度条、暂停、继续、后台、取消与失败统计；不在 ReaderUI 执行批量网络请求。
- 评论完成后不再自动打开评论长列表；保留原有手动查看、正文/带评论 EPUB、下载内存保护、自动/手动进度同步及 GitHub Tag/手动发布流程。
- 真机微信读书记账、Kindle 翻页流畅性及 OTA/CI 真实发布仍需设备与线上验收；本地测试不能替代真实服务器结果。

# v6.1.0-beta.19 · 2026-10-28

- 公开想法采用尽力而为首批获取；单条异常不再将整批正常评论标记为失败，成功数据直接保存，更新时不向读者显示获取数量、失败范围或正文定位统计。
- 保留 Web/Gateway 交叉核查及章节公开想法补充来源；评论缓存只增量合并，不删除历史评论和收藏；暂不追求所有历史评论的深度分页。
- 支持单条及批量放弃待上传阅读进度，使用 progress_epoch 使旧后台回调失效；保留 Kindle 当前阅读位置、个人批注、评论及未确认阅读时间；首页同步提醒可单独隐藏。
- 修正微信书架移除授权路径：删除始终通过已授权 E-Ink 写入，Web 可用于云端状态回读；账号未授权时提供扫码入口，写入结果未知时不盲目重复提交。
- 按书籍下载状态精简长按主菜单，将带评论 EPUB、章节下载和阅读状态集中到更多操作；恢复带评论版为独立可选下载类型，默认仍为纯正文。
- 主页绘制与延迟刷新避开前景模态弹窗，减少 E-Ink 白块和按钮遮挡风险，仍需 Kindle Voyage 实机验收。
- 保留 Kindle 精确位置优先、时间上报安全保护和现有 GitHub 手动版本号/自动 Tag 发布流程；新增回归覆盖，未改动用户数据库 Schema。
