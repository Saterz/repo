# v1.2.3-beta.2 · 2026-10-11

## 更新说明

- 元数据：微信读书源现在会自动更新skill版本信息，不再因skill版本升级而丢弃搜索结果
- 元数据：封面编辑器在缺少 API Key 时会直接弹框填写，填完自动继续封面搜索，而不是只弹提示让用户去设置里手动配置
- 快捷操作：微阅标注（拉取微阅想法的内置动作）改为依赖插件weread，配套修改.koplugin，不再依赖wereadannotationlite.koplugin

> 配套修改weread.koplugin
- 添加“拉取当前章节想法”菜单，点击自动拉取当前章节想法并后台自动预提下一章节想法（实现翻到任意章节均会自动拉取匹配当前章节想法的效果），可注册快捷手势。
- 整本下载伴随失败章节时会无法打包成EPUB，修改后即使有失败章节也可以打包成EPUB，失败章节正文内容提示"获取内容失败“
