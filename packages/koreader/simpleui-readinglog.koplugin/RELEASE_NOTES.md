# v1.9.0 · 2026-10-24

New themes: Forest (soft greens), Latte (warm browns) and Night Sky (deep blue, also a Night Mode Theme choice). New Progress Style: draw every ring as Rings, Bars, Dots or Pixel Blocks. New Chart Style: bar charts as Bars, Line or Dots On Stems.

# v1.8.1 · 2026-10-24

Refined critter insights: Yearly goal pace as a finish rate ("one every 3 days"), a weekend/weekday verdict that sticks instead of flipping weekly, milestones by finish date, and quiet-day nudges that stay away once passed on.

# v1.8.0 · 2026-10-24

Tiny Critter: SimpleUI 3.0's Tiny Critter now peeks into each Dashboard page with a remark about that page's numbers. Tap it for another remark. Turn it off in Reading Log Settings → Critter Remarks. Without SimpleUI 3.0's Tiny Critter, the pages look as before.

# v1.7.2 · 2026-10-23

Tab Bar Position refinement: moving the tab bar no longer shrinks the dashboard heading — only the cards make room. Layout-geometry diagnostics for the SimpleUI diagnostics patch. Compatible with SimpleUI 3.0.0.

# v1.7.1 · 2026-10-23

SimpleUI wallpaper support: below Solid Background Opacity the dashboard page is left clear so the wallpaper shows between the cards (titles get framed plates), plus a Tab Bar Position setting.
