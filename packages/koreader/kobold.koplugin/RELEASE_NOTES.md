# v1.2 · 2026-10-21

## Kobold 1.2

<!--kobold-->
Instant return after closing a book, new icons, redesigned popups and settings, a Wi-Fi switch, and a cleaner Series tab.
<!--/kobold-->

### New

- **Instant return** after closing a book, with no flash of KOReader's file browser
- **Opening and closing panel**, an optional "Opening Book" / "Closing Book" panel instead of KOReader's messages. Off by default, turn it on in Settings 
- **Wi-Fi switch** in the Wi-Fi popup to turn Wi-Fi on or off, plus a Wi-Fi Settings link to pick a network
- **Book menu on Home**, hold any of the 4 recent books for the same menu as the "..." in My Books
- **Setting tooltips**, tap a setting's name to see what it does

### Improved

- **New icons** for the status bar and navigation bar, white on black in night mode
- **Popups** have square corners and an arrow pointing at the icon that opened them
- **Settings** is a compact panel that fits more per page, with a page bar on the side
- **About** is now a panel like Settings
- **Series tab** shows the author and book count, with a small stack above the cover for series with more than one book
- **Battery** shows its charge level while charging, with the lightning bolt on top
- **Home** keeps the same collection and covers instead of changing them every time you close a book

### Install

1. Download `Kobold.koplugin.zip` below
2. Extract it and copy the `Kobold.koplugin` folder into KOReader's `plugins` folder
3. Restart KOReader and open Kobold, or set it under **Start with > Kobold Home**

On 1.1 or newer? Use **More > Check for updates** in Kobold.

To uninstall, delete the `Kobold.koplugin` folder and restart KOReader.

# v1.1 · 2026-10-16

## Kobold 1.1

<!--kobold-->
New Files tab, grid view for Series, KOReader gestures in Kobold, a clock popup, night mode toggle, update checks from the More tab, and lots of fixes.
<!--/kobold-->

### New

- **Files tab** in My Books, a simple file browser you can turn on in Settings. Hold a folder for KOReader's folder options
- **Grid view for Series**, plus the list or grid toggle on the Series tab
- **Series line** under each book title in My Books, like "SERIES NAME... - 1"
- **Last opened** sort in My Books
- **Clock popup**, tap the time to switch between 12 and 24 hour. Follows your KOReader setting by default
- **Night mode** toggle in the brightness popup
- **Check for updates** in the More tab, downloads and installs new versions over Wi-Fi
- **Open books with** setting, choose single tap, double tap, or follow KOReader
- **Add books to a collection** from a picker with checkboxes

### Improved

- **KOReader gestures** now work in Kobold, including edge swipes for brightness and warmth, corner taps and multiswipes
- **Thin outline** around every book cover
- **Settings** splits into pages on smaller screens
- **Book info edits** made in KOReader show up in Kobold right away
- **Opening Kobold while reading** closes the book first, so every menu works
- **About page logo** shows properly in night mode
- **Kobold** now sits in KOReader's Tools menu instead of More tools

### Install

1. Download `Kobold.koplugin.zip` below
2. Extract it and copy the `Kobold.koplugin` folder into KOReader's `plugins` folder
3. Restart KOReader and open Kobold, or set it under **Start with > Kobold Home**

Already on 1.0? Just copy the new folder over the old one.

To uninstall, delete the `Kobold.koplugin` folder and restart KOReader.

# v1.0 · 2026-10-14

## Kobold 1.0

First release of Kobold, a home screen for KOReader with the calm, familiar look of your e-reader's original software.

### What's in it

- **Home** with the books you're reading, your library and a collection at a glance, plus reading stats
- **My Books** with Books, Authors, Series and Collections tabs, in list or grid view
- **Filter and sort** by status, date added or title
- **Collections** you can create, rename, delete and fill with books right from Kobold
- **Status bar** with quick brightness, warmth, Wi-Fi and battery popups, plus file search
- **Reading stats** on Home that you can customise, with your own text and tap actions
- **Settings** page for books per page, battery style, stats and more
- **Returns to Kobold** after you close a book
- **Fast loading**, with covers and book info cached

### Install

1. Download `Kobold.koplugin.zip` below
2. Extract it and copy the `Kobold.koplugin` folder into KOReader's `plugins` folder
3. Restart KOReader and open Kobold, or set it under **Start with > Kobold Home**

To uninstall, delete the `Kobold.koplugin` folder and restart KOReader.
