# 3.0.0 · 2026-10-23

What's New in Simple UI v3.0

- Add Accent Color customization for supported color devices (with grayscale fallback for monochrome displays);
- Overhaul Reading Stats module with new Detailed Mode, built-in charts, category-grouped metrics, paginated grid layout, and per-card visual customization;
- Add live layout preview in settings and quick-adjust popup menu for Bento Grid homepages;
- Revamp Library UI with a compact tabbed title bar, resizable navigation elements, and Series sub-groupings in Author/Tag views;
- Introduce Tiny Critter reading companion with customizable decor, interactive dialogs, and daily challenges;
- Add Tabbed Grid module to categorize and jump between book lists directly from the home screen;
- Add dedicated Reader Mode to the Quick Settings bar;
- Add new "Flow" layout option to the Coverdeck module;
- Add backdrop opacity controls to improve readability over active wallpapers;
- Redesign dialog box UI across the entire plugin for a cleaner, cohesive aesthetic;
- General bug fixes and performance optimizations.

# 2.6.0 · 2026-08-26

What's New in Simple UI 2.6.0:

- Reading Heatmap: Added a new Reading Heatmap module.
- Customization: Introduced a browsable asset picker for easier selection and installation of icons and wallpapers.
- Clock: Added independent size controls for the clock face, date, and battery text.
- Cover Deck: Added a per-instance progress badge to the Cover Deck module.
- To Be Read: Added an option to automatically remove books from your TBR list once they are marked as finished.
- Quick Actions: Optimized and unified the behavior of Quick Actions across the interface. Fixed an issue where Custom Screen Quick Actions were missing from menus, and fixed a bug when tapping the bookmark browser.
- Bug Fixes: Fixed frame and background box misalignment with section labels across homescreen modules. Truncated the compact stats row to prevent layout stretching. Fixed cover scaling issues in the default layout, and ensured hidden collections remain visible in the Arrange screen.
- General bug fixes and quality-of-life optimizations.
