# v1.1.0 · 2026-10-14

### NEW

**Swap sides.** This setting is for people who prefer brightness on the right edge and warmth on the left. It’s off by default, so nothing changes unless you turn it on.

**Find it in:** Top menu → gear icon → Taps and gestures → Live Light → Swap sides.

### CHANGED

**The brightness number.** Instead of showing a percentage, the brightness level now uses the same number you’re used to on your device. On a Kobo, that’s still a number between 0 and 100. On a Kindle, it now goes from 0 to 24.

(And if you’re Nigel Tufnel, your brightness [goes to eleven](https://youtu.be/uMSV4OteqBE?t=78))

### TO INSTALL OR UPDATE

Download `livelight.koplugin.zip` below and unzip it. Copy the `livelight.koplugin` folder into KOReader’s `plugins` folder (on a Kobo, `.adds/koreader/plugins/`), replacing the old one if you’re updating. Then restart KOReader. Your settings are kept.

<hr>

If this update broke anything for you, or the levels aren’t right, please [let me know](https://github.com/ironicsans/livelight.koplugin/issues).

# v1.0.0 · 2026-10-12

First release.

Brightness (left edge) and warmth (right edge) follow your finger as you slide, with a small box showing the level.

**To install:** download `livelight.koplugin.zip` below, unzip it, and copy the `livelight.koplugin` folder into KOReader's `plugins` folder (on a Kobo, `.adds/koreader/plugins/`). Then restart KOReader.

Tested on a Kobo Clara BW running KOReader 2026.07.02. See the README for details and known limitations.
